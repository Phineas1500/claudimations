# claudimations

Short vertical brainrot videos (1080×1920, 30 fps) starring a paper-cutout Claude spark. Every frame and every sound effect or note of music is generated by code, rendered on a Raspberry Pi 5. There's no stock footage, no samples, and no video editor. Narration comes from a local Piper TTS voice.

Each episode is a true story of something Claude actually did in a coding session, told in the style of short-form "brainrot": karaoke captions, running gags, a fake-out, and a beat drop.

| Episode | What happens |
|---|---|
| `01-limewire` | *POV: your user sends you a LimeWire link in 2026.* Encrypted file names, a privacy pop-up, a user-agent disguise, a 1 KB thumbnail fake-out, and a phonk heist. |
| `02-spark-joy` | *Tidying up a Raspberry Pi: does this spark joy?* 18 GB of JSON, 1,802 unused npm packages, a llama guarding `/tmp`, a misread log, and a hydraulic press. |

## Layout

```
engine/
  js/core.js       canvas setup, fonts, easing, paper textures, "sticker" cut-out shapes, grain
  js/captions.js   karaoke captions driven by word timings
  js/mascot.js     the spark character (expressions, disguise, nametag)
  js/ui.js         retro OS windows, modern web bits, cursors, phone UI, confetti
  js/render.js     frame renderer → ffmpeg (parallel workers, stills/contact sheets)
  py/tts.py        Piper narration + estimated word timings
  py/synth.py      numpy/scipy synth: drums, 808, cowbell, FM keys, plucks, music box, wobble bass, SFX
reference/ANALYSIS.md   notes on the videos and article that inspired this
videos/NN-name/
  script.py        narration lines (shown vs spoken words, pauses, scene tags)
  build_voice.py   step 1 → build/narration.wav + build/timeline.json
  build_audio.py   step 2 → build/audio.wav (music/SFX mixed against the timeline) + build/cues.json
  scenes.js        step 3: draws each frame from the timeline + cues
```

## Setup

Needs node ≥ 18, python 3 (with `venv`), ffmpeg and curl.

```sh
./setup.sh   # npm deps, python venv, fonts, TTS voice (~400 MB of downloads)
```

## Build an episode

```sh
cd videos/01-limewire
../../engine/.venv/bin/python build_voice.py      # re-run only when the script changes (TTS timing varies run to run)
../../engine/.venv/bin/python build_audio.py
node ../../engine/js/render.js . --stills 1,5,12 --sheet   # quick visual check → build/stills/sheet.png
node ../../engine/js/render.js . --workers 3 --out build/final.mp4
```

A full render takes about 5–9 minutes on a Pi 5 (~0.4 s per frame per worker).
